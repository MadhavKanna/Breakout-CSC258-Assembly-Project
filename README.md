# CSC258-Assembly-Project
To run the program, download the MARS program,(link: https://courses.missouristate.edu/KenVollmar/mars/). Connect the Bitmap Display and Keyboard and Display MMIO simulator panels under tools. Make sure to configure the Bitmap Display according to the included specification and connect both panels to MIPS. Click "Assemble" and then "Go" under the Run menu. Start playing game by typing s into the Keyboard and Display MMIO simulator to start. Move paddle left and right using a and d keys. Press q to quit, and x to restart. Have fun!

######################## Bitmap Display Configuration ########################
# - Unit width in pixels:       8
# - Unit height in pixels:      8
# - Display width in pixels:    256
# - Display height in pixels:   256
# - Base Address for Display:   0x10008000 ($gp)
